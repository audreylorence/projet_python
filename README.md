
# Projet d'analyse de données avec Python

## Présentation du projet

Ce projet s'inscrit dans le cadre de ma formation de Data Analyst et a pour objectif de mettre en pratique Python pour l'analyse et la visualisation de données.

L'analyse porte sur un jeu de données lié à des campagnes publicitaires digitales.

L'objectif est d'explorer les données, d'identifier les tendances et relations entre les différentes variables, puis d'en tirer des insights pertinents d'un point de vue business.

## Objectifs

L'analyse vise notamment à :

- Explorer et comprendre la structure du jeu de données
- Vérifier et préparer la qualité des données
- Identifier et traiter les valeurs manquantes
- Réaliser une analyse exploratoire des données
- Étudier les performances des campagnes
- Identifier les tendances et relations entre les différentes variables
- Créer des visualisations permettant de faciliter l'interprétation des résultats
- Traduire les résultats de l'analyse en insights business

## Outils et technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Données

Le jeu de données contient différentes informations relatives à des campagnes publicitaires digitales, notamment :

- Impressions
- Clics
- Dépenses publicitaires
- Conversions
- Chiffre d'affaires
- Durée moyenne des sessions
- Engagement
- Caractéristiques des campagnes

Le jeu de données utilisé pour l'analyse est disponible dans le dossier `data/`.

## Étapes de l'analyse

### 1. Exploration des données

- Découverte de la structure du dataset
- Analyse des types de données
- Vérification des valeurs manquantes
- Recherche de doublons
- Analyse des premières statistiques descriptives

### 2. Nettoyage et préparation des données

- Gestion des valeurs manquantes
- Vérification de la qualité des données
- Préparation des variables nécessaires à l'analyse

### 3. Analyse exploratoire

- Analyse des statistiques descriptives
- Étude de la distribution des variables
- Comparaison des performances des campagnes
- Analyse des relations entre les différentes variables

### 4. Visualisation

Création de visualisations avec Matplotlib et Seaborn afin de :

- Comparer les performances
- Identifier les tendances
- Mettre en évidence les différences entre les campagnes
- Faciliter l'interprétation des résultats
